# 🏋️‍♂️ Fitness Equipment Rental Calculator

A lightweight, responsive web application built to streamline pricing calculations and quote summaries for equipment rental businesses. This interactive tool replaces manual calculation spreadsheets with an automated, user-friendly interface.

## 🌟 Key Features

* **Dynamic Subtotal Calculation:** Instantly computes equipment costs based on item selection and rental duration.
* **Automated Bulk Discounts:** Automatically applies a **10% discount** on rental periods of 7 days or more.
* **Optional Add-ons:** Supports dynamic fee inclusion, such as flat-rate home delivery ($30).
* **Tax Automation:** Calculates a 7% sales tax on the post-discount subtotal and delivery total.
* **Detailed Price Breakdown:** Renders a clean itemized receipt showing subtotal, discounts, fees, tax, and grand total.
* **Responsive UI:** Clean CSS styling designed for optimal mobile and desktop user experience.
